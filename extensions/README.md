# Browser extensions

Merged **QE Consultancy** extension (Manak Test Request + copy/paste + bulk fill) ships as two browser-specific copies:

| Folder | Browser |
|--------|---------|
| [`qe-consultancy-chrome`](qe-consultancy-chrome/) | Chrome, Edge, Brave, other Chromium browsers |
| [`qe-consultancy-safari`](qe-consultancy-safari/) | Safari 16.4+ (Xcode wrapper in `macos/`) |

Original source folders (`manak-test-request`, `Copy Paste`) are kept for reference. Load the merged folders, not the originals.
